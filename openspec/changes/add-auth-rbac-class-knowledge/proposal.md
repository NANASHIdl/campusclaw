# Change: add-auth-rbac-class-knowledge

## Why

CampusClaw 是面向中小学的教研智能体，覆盖学情分析、备课、命题、课堂与教研协同，教研材料与知识库是其能力底座。当前材料分散在群文件与网盘中，教师难以检索复用，班级之间也缺少数据边界。本变更先建立**身份、角色与班级隔离**，让教师登录后上传并管理本班材料，学生仅可查看本班内容，为后续检索与智能问答打基础。

## What Changes

- **系统架构**：采用 `web`（Nginx，唯一对外端口）+ `api`（Go，信任边界）+ `db`（MySQL，不映射端口）三容器；认证、授权、班级隔离与上传校验全部在 Go 服务端完成。
- **用户登录与服务端会话**：教师、学生两类角色；账号密码登录；Cookie 仅保存随机会话标识，角色与班级保存在服务端；**登录成功必须换发新的会话标识**（防会话固定）。
- **统一失败响应**：账号不存在、口令错误与触发限流对外使用相同的状态码与文案，真实原因仅写入服务端日志。
- **角色权限**：教师可上传与管理本班材料；学生对本班材料只读；学生调用上传接口 MUST 被拒绝（HTTP 403），且发生在文件落盘之前。
- **班级隔离**：班级为数据边界，取自会话；请求中自行声明的角色与班级一律丢弃；跨班访问与记录不存在对外 MUST 返回同构的 404。
- **材料上传与知识库入库**：仅接受 `.txt`/`.md` 并设大小上限；服务端生成存储名，材料行与知识库正文在同一事务提交，失败回滚并清理文件。
- **材料下载鉴权**：通过 `GET /api/materials/{id}/file` 提供下载，读取文件前完成认证与班级校验；上传目录不作为静态资源暴露。
- **数据模型**：`classes`、`users`、`sessions`、`materials`、`knowledge_entries` 五张表，`materials` 与 `knowledge_entries` 携带非空且带索引的租户列 `class_id`；种子含两个可区分班级及各自教师与学生账号。
- **安全与运行**：口令 MUST 哈希存储，禁止明文；数据库连接口令与会话密钥仅通过环境变量注入；标准启动方式为 Docker Compose，数据存放于数据卷，`down` 后 `up` 数据仍在。
- **文档**：README 三行说明（价值、场景、不做）与 Compose 启动方式；新增 `.env.example`。

## Capabilities

### New Capabilities

- `auth-upload`：服务端会话与登录换发、统一失败响应、按角色授权、按班级隔离（同构 404）、教师上传入库、材料下载鉴权、预置数据、口令与会话密钥、Docker Compose 与 `/health` 等可验收行为。

### Modified Capabilities

（无——`openspec/specs/` 尚无主规格。）

## Impact

- 新建 `api/`（Go 服务：认证、材料、上传、下载、健康检查）与 `web/`（Nginx + 静态 SPA）。
- 新建 MySQL 持久层：`classes`、`users`、`sessions`、`materials`、`knowledge_entries` 五张表与种子数据。
- 替换第 2 课的 Flask + SQLite 单容器实现：移除 `app/`、`scripts/`、`run.py`、`requirements.txt` 与根 `Dockerfile`。
- 项目根更新 `docker-compose.yml`（三服务 + 命名卷）与 `.env.example`；依赖清单为 `api/go.mod`。
- 可运行实现按 `tasks.md` 在 Apply 阶段完成。

## Non-goals（非目标）

本 change **明确不做**以下内容（避免范围膨胀）：

- **检索与问答**：不做 RAG、全文检索、智能问答、基于知识库的对话（第 4 课）。
- **文档解析扩展**：不做 PDF/Word/图片解析、在线编辑、切分与向量嵌入。
- **对话助手**：不做聊天界面、Agent 编排、技能包运行时。
- **作业流程**：不做作业提交、批改、成绩、审计与错题本。
- **身份与企业集成**：不做多校/多租户、OAuth/OIDC、SSO、短信/邮箱验证码登录、注册与找回密码、平台级超级管理员。
- **生产运维**：不做 K8s、多副本高可用、共享限流存储、完整 CI/CD 流水线；标准启动为 Docker Compose 本地/演示环境即可。
- **前端替代服务端安全**：不以隐藏按钮、禁用表单作为权限或班级隔离的唯一手段。
